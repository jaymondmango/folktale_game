### Folktale: The Mansion

This game was made for Hack Club's, "Folktale."

#### Context:
The game is a story game, where you navigate through different puzzles and questions. Play to find out what is at the end!

##### Keybinds

"a": answer choice "a"

"b": answer choice "b"

"c": answer choice "c"

"d": answer choice "d"

"e": answer choice "e"


"yes": answer choice "yes"

"no": answer choice "no"
